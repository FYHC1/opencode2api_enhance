CONC 并发回归测试面板

同源调用 /api/admin/*（dev 无密码直接可用；若被要求登录请先填密码登录）。每个按钮完成一项检测并输出 耗时/状态/判定。

C3-1 统计页实时可读

高频请求后 /stats 返回应实时、可解析 JSON。

C3-2 / C8-1 日志秒开

大日志下 call-log 读取应秒开（预期 < 1s）。

C3-3 清空日志

清空后读取应为 0 条，旧日志不再出现（含 .1 旧段）。

C3-4 call_log_max 热加载

改 call_log_max 保存后内存已聚合日志不丢。

C4-2 大批量导入（300+）

填订阅 URL（需可用源；可先起本地 mock）导入大批节点。

C4-3 双订阅并发不丢

两个订阅同时导入，两组节点应都在节点池。

C4-1 一键重启池

几十个实例时停止阶段应明显变快（并行 kill）。

C5-1 网关并发拉起单进程

5 个并发 status（模拟双 tab），应全部返回且 running 一致；进程唯一性请到任务管理器核对。

C5-2 网关密钥热更

改 gateway key 保存后应立即生效，不闪 401。

C8-2 统计聚合/重置并行

几十实例下聚合秒出；重置并行完成（不串行等 N×6s）。

C10-3 并发 503 上限

>512 并发流式连接应超限返回 503。此按钮打 /v1/models 高并发，观察状态码分布。

C7-1 慢厂商不拖累目录

/v1/models 在刷新周期内应返回（不被慢上游拖死）。
