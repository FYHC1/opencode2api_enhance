## 一、最初目标（产品设想）

用户期望的 **Rust 客户端 + Web 界面**：

1. 输入 **订阅链接** → 点「获取」→ 得到节点列表  
2. **新增实例**：名称、端口、选择节点  
3. **启动 / 停止** 互斥；可多开  
4. 对外使用：`http://主机:端口/v1`  
5. 打包物：`opencode2api` + `sing-box` + 管理器  

架构：

```
用户 → :端口A /v1 → opencode2api → sing-box(SOCKS) → 节点A
用户 → :端口B /v1 → opencode2api → sing-box(SOCKS) → 节点B
```
