# 端到端验收清单（需部署机 / 用户配合）

> 本文档列出执行计划（EXECUTION-PLAN.md）中各阶段的**端到端验收项**——
> 这些项需要真实环境（部署机 + Clash + 真实上游 + 多窗口客户端）才能验证，
> 子代理只保证自动化验证（单测/集成/构建/走查），本清单由用户在部署机逐项执行并打勾。

- 状态图例：⬜ 未执行 / 🔶 执行中 / ✅ 通过 / ❌ 失败（失败项回填各阶段「遗留」小节）

## E1 上游代理出口

| # | 验收项 | 命令 / 步骤 | 状态 |
|---|---|---|---|
| E1-1 | 设置页出现「代理出口」区块 | 打开设置页，找到输入框 placeholder `socks5://127.0.0.1:7897` | ⬜ |
| E1-2 | 填写 Clash 代理后生效 | 填 `socks5://127.0.0.1:7890`（本机 Clash 实测端口）→ 保存 → 重启实例/网关 | ⬜ |
| E1-3 | 请求上游返回 200 | `curl.exe http://127.0.0.1:40080/v1/models -H "Authorization: Bearer sk-unified-local"` | ⬜ |
| E1-4 | 批量扫描不再全挂 | 节点扫描页执行扫描，观察不再 0/N 全挂 | ⬜ |
| E1-5 | 未配置时行为不变 | 清空代理出口 → 重启 → 请求正常走 sing-box 出口（回归） | ⬜ |

> 注意：本机 Clash 实测监听 7890（mixed-port）与 9097（外部控制），文档示例 7897 需按实际端口填。

## S1 竞速整体预算

| # | 验收项 | 命令 / 步骤 | 状态 |
|---|---|---|---|
| S1-1 | 挂起节点时请求 ≤10s 有结果 | 临时断一个节点的 sing-box → 发请求 → 观察 ≤10s 内得到响应或明确错误，不无限悬着 | ⬜ |

|---|---|---|---|
