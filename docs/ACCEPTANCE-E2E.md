# 端到端验收清单（需部署机 / 用户配合）

> 本文档列出执行计划（EXECUTION-PLAN.md）中各阶段的**端到端验收项**——
> 这些项需要真实环境（部署机 + Clash + 真实上游 + 多窗口客户端）才能验证，
> 子代理只保证自动化验证（单测/集成/构建/走查），本清单由用户在部署机逐项执行并打勾。

- 状态图例：⬜ 未执行 / 🔶 执行中 / ✅ 通过 / ❌ 失败（失败项回填各阶段「遗留」小节）
