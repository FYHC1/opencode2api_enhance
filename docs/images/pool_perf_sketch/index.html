性能模式如何工作： 你的请求到达网关后，同时发往 3 个健康节点（候选池按质量分排序）—— 哪个先响应就用哪个，其余立即断开。效果：响应速度 = 最快节点的速度， 单个节点断断续续（10s 无响应又恢复）完全不影响你，因为总有快的先回来。 每次竞速结果自动回写质量评分，节点恢复后自动回归候选池，无需手动检查。
竞速副本：3（可配 1~4） 探活间隔：30s 评分窗口：10min 熔断阈值：连续 3 次 半开回归：60s ⚠ 竞速 N 个节点 = N 份上游配额消耗
