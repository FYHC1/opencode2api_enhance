# 常见问题（FAQ）

使用 opencode2api 过程中遇到的常见问题与解决方法。遇到问题先看这里，没有收录的欢迎提 Issue。

---

## 1. 报错 `400 ... max_tokens is too large: 393216. This model supports at most 131072 completion tokens`

**完整报错：**

```
400 Error from provider (Console): Upstream request failed: [bad_request]
bad request: max_tokens is too large: 393216. This model supports at most
131072 completion tokens.
```

**报错含义：**

报错字面意思是请求的 `max_tokens`（393216）超过了模型上限（131072），但**这通常不是模型或参数配置的问题**，而是**实例构建/网络环境不对**导致的连锁反应。

**常见原因：**

1. **构建实例时系统代理没有开启**——实例走了错误的网络路径，上游返回异常
2. **节点有问题**——部分 cf 优选节点不稳定，也会触发类似报错

**解决办法：**

**① 快速尝试：**

1. 删除出问题的实例
2. 打开系统代理
3. 重新添加实例并激活

**② 完整步骤（彻底解决）：**

1. **完全退出** opencode2api 管理器
2. 软件启动前，**先启动 Clash 并打开系统代理**（全局 / 规则模式均可——总之先开启系统代理）
3. 在**代理开启的状态下**进行检查、添加实例等操作，然后启动实例，即可正常使用
4. 之后保持代理开启，**平时不要关闭**

**③ 以上都不行 → 节点问题：**

部分 cf 优选节点有问题。判断方法：换一个模型进行对话测试——如果**其他模型能通，只有 deepseek 报「超过最大 token」**，基本可断定是节点问题，换一个节点重试即可。
